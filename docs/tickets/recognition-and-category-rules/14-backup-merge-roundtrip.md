# 14：完整恢复与合并新增分类和识别状态

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

用户可把包含自定义分类、规则、银行证据、时间依据及未完成识别任务的完整备份恢复或合并到另一账本，并继续处理而不重分或重扣。

本项覆盖父规格验收编号：T32、T29、T30。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 各功能已有新增字段的基本持久化和备份；本项完成跨功能的完整恢复、合并冲突处理及旧版本端到端兼容。
- [ ] 完整覆盖分类稳定标识、规则与配置快照、人工分类保护、订单内容、商家／服务商／凭证来源、时间来源与时区、替代映射、批次决定及子回执。
- [ ] 新备份往返后用户能继续编辑规则、查询旧账单和恢复待处理任务；不静默丢字段、重新分类、重判已完成候选或重复钱包影响。
- [ ] 兼容旧备份、旧任务和 CSV 明确类别，保留原名称及“一级/二级”；数据库和备份版本按实施时实际分支递增。
- [ ] 合并时按方向、名称及稳定标识处理冲突，不静默覆盖本地用户规则；冲突导入规则停用并给出可理解的原因。
- [ ] 分类删除替代映射与旧任务快照共同恢复后不复活旧分类；恢复仍遵守当前采集授权，不能借快照恢复权限。
- [ ] 验证部分成功批次、全部跳过、缺时间、缺截图、人工分类、重复合并和恢复失败回滚，断言类别、明细及余额一致。
