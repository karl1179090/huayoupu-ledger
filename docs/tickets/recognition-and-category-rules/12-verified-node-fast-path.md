# 12：已验证单笔版式直接使用无障碍节点

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

现场已验证的单笔支付结果直接用节点识别、保留截图并正常入账；未知或异常版式回退一次 OCR，结果可走同一个分类和提交入口。

本项覆盖父规格验收编号：T01、T02、T05。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 采集同一有效窗口的节点快照，保留分区所需层级、位置、文字和状态，继续执行授权、白名单、窗口归属及敏感／截断树检查。
- [ ] 建立可记录应用版本、系统、设备和验证范围的版式适配；只有真实同页面节点与截图对照通过的版式可启用快速路径，合成样例本身不足以启用。
- [ ] 已验证单笔版式产生有效候选时不调用 OCR，截图仍留档；节点候选接入统一时间、分类、钱包及幂等提交入口，不复制一套业务规则。
- [ ] 未知版式、关键解析失败或冲突时执行一次 OCR，图片导入直接 OCR；缺商家、商品、订单号或时间不单独追加 OCR。
- [ ] 节点读取不能声称证明全部像素文字已取得，不补猜页面缺失字段；没有真实节点对照样本时保留 OCR 路径并说明未覆盖版式。
- [ ] 截图与节点关联同窗口同交易，离开页面后使用保存证据继续处理；授权撤销、窗口变化、密码、输入、空树和截断不绕过原检查。
- [ ] 节点来源及证据可持久保存与查看，记录可比较的阶段耗时和选路结果；测试通过提交结果及 OCR 调用次数证明选路与复用。
