# 02：统一分类目录并提供基础管理

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

用户在设置中按收入、支出添加分类、改名、排序和选图标，记账、编辑、筛选及统计使用同一目录；升级后原有分类归属保持不变。

本项覆盖父规格验收编号：T23、T24、T34。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 设置提供分类管理入口及收入／支出分组，支持添加、改名、排序、图标选择，所有选择与统计入口读取统一目录。
- [ ] 分类使用稳定标识；先以兼容方式增加标识并映射旧名称，收入与支出分别保留不可删除的系统兜底“其他”。
- [ ] 同方向规范化名称唯一，跨方向同名保持独立；详情编辑校验分类存在且方向匹配。
- [ ] 旧名称及归属原样保留，不自动合并长短名称，不把陌生类别丢到“其他”；CSV 的“一级/二级”保持完整单层名称。
- [ ] 新预设使用统一界面短名称，现有识别输出映射到目录；本人互转及手续费继续使用专门语义。
- [ ] 无引用类别可删除；有引用类别在后续替代迁移完成前保持不可直接删除，给出明确说明，不造成失效引用。
- [ ] 本项新增目录状态随备份往返并兼容旧备份及 CSV；升级、改名及重复恢复不修改金额、时间、方向、钱包或余额。
- [ ] 通过设置操作、手动记账、详情、筛选和统计验收，覆盖迁移、跨方向同名、排序持久化及非法名称。

## Blocked by
