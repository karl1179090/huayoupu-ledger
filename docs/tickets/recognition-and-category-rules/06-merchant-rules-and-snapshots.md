# 06：按商家自动分类并固定任务规则快照

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

用户在设置中建立按商家匹配的自定义规则，新识别按规则归类；修改规则不会改变历史账单、人工分类或已排队任务。

本项覆盖父规格验收编号：T27、T29、T30、T34。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 提供自动分类规则入口、列表和编辑器，首个完整流程支持单条商家包含／等于条件、收入或支出方向、目标分类、启停及排序。
- [ ] 人工指定分类优先，其次顺序第一条命中的自定义规则、启用内置规则和同方向“其他”；保存时校验关键词、方向和有效目标。
- [ ] 任务创建时固定完整规则定义、顺序、状态及目标，重试与恢复复用；旧任务按迁移基线处理，不临时读取未来新规则。
- [ ] 保存分类来源、人工选择状态、规则版本及必要命中说明，账单显示简短原因；更改规则只影响后续新任务。
- [ ] 既有账单和同单补充识别保留类别；旧日期的新凭证可应用新规则，匹配已有交易则保留原类别；手动及 CSV 明确类别保持。
- [ ] 类别改名不改变稳定目标；在替代迁移完成前，拒绝删除被规则或排队快照引用的类别。
- [ ] 本项规则、分类来源和快照随备份保留；同方向冲突不能静默覆盖本地配置。
- [ ] 通过设置保存规则→识别→详情的完整流程，覆盖首条命中、停用、兜底、人工保护、排队期间修改、跨进程恢复和旧任务升级。
