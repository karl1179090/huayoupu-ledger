# 13：节点识别容忍普通截图失败并复用图标

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

可靠节点已取得时，普通截图失败仍可保存账单并标明缺图；商家图标优先复用缓存，无缓存显示默认图标。

本项覆盖父规格验收编号：T04、T06。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 仅在可靠节点候选已通过采集与业务检查时，普通截图失败或超时允许继续保存，账单与任务结果明确标示缺截图。
- [ ] 系统保护、隐私、授权或窗口身份检查失败继续停止；不得补截其他页面或从新窗口补旧交易字段。
- [ ] 节点路径优先使用可靠商家图标缓存，无缓存时使用默认图标，不单为图标运行完整 OCR。
- [ ] 后续正常 OCR 得到的可靠图标可以共享，不能把服务商、银行作者或未知占位名错误映射为商家图标。
- [ ] 缺图状态、证据来源及图标行为经重启和备份恢复仍一致，恢复不会重复入账或截图。
- [ ] 故障注入覆盖普通失败、超时、保护窗口和切页，断言保存条件、缺图提示、OCR 次数及图标结果。
