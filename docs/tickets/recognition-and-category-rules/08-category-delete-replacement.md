# 08：删除分类时迁移账单、规则及排队目标

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

用户删除被使用的分类时先看到影响，再选择同方向替代分类，一次完成账单和规则迁移；排队任务使用有效替代目标。

本项覆盖父规格验收编号：T25、T29。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 删除前统计并展示受影响的账单、规则及排队配置；要求选择存在且同方向的替代项。
- [ ] 无引用分类可直接删除；禁止替代自身、跨方向替代、无效目标及删除受保护“其他”。
- [ ] 类别删除、已有账单引用及规则目标迁移原子完成，任一步失败整体回滚。
- [ ] 为不可变任务快照保留明确替代映射，保持原条件和优先级，重试／恢复不会复活旧类别；后续条件扩展不影响替代机制。
- [ ] 更改仅作用于分类归属，不改变金额、时间、方向、钱包或余额，不触发全量重新匹配规则。
- [ ] 删除及替代映射经过重启与备份仍有效；现有规则解释可追溯，不新增独立的分类删除撤销功能。
- [ ] 通过设置删除→历史记录查看→排队任务继续处理验证一致性，注入迁移失败并断言无部分写入和资金变化。
