# 09：测试规则并从账单预填新规则

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

用户可用测试输入或已有账单查看最终命中及原因，也可从账单编辑页预填规则，经保存后影响未来识别。

本项覆盖父规格验收编号：T31、T34。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 规则页面支持手工测试输入和只读选择已有账单，使用与正式识别一致的匹配语义。
- [ ] 测试显示各条件是否满足、前置规则截获、最终分类及简短理由，涵盖自定义、内置与“其他”兜底。
- [ ] 测试过程不修改账单、类别、钱包、规则配置或已有任务快照。
- [ ] 账单编辑页提供“据此创建规则”预填入口，由用户核对条件和目标后保存；只改账单类别或取消编辑不会创建永久规则。
- [ ] 新保存规则只影响后续新任务，测试数据的缺字段、来源及订单内容边界与真实识别一致。
- [ ] UI 验收覆盖进入、预填、取消、非法输入、成功保存和规则优先级解释，并验证测试前后账本与余额完全不变。
