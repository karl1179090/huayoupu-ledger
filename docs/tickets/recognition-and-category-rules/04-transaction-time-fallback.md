# 04：识别交易日期并固定缺时间回退

## Parent

[Issue #5：交易识别与自动分类升级规格](https://github.com/karl1179090/huayoupu-ledger/issues/5)

## What to build

凭证有日期时按页面日期记账，没有可用交易时间时直接按本次识别时间入账，历史图片也适用；重试和跨日恢复保持日期稳定。

本项覆盖父规格验收编号：T13、T14、T15。继续遵守父规格的离线处理、合成测试数据和不追溯旧账单等约定；在本项完成时执行受影响的检查。

## Acceptance criteria

- [ ] 支持完整年月日、日期时间分行、仅日期及月日缺年；仅日期保留原日期与精度。
- [ ] 缺少可用交易时间时使用首次实际开始识别的时间，不新增时间专用待确认流程；实时凭证和历史图片行为一致。
- [ ] 任务持久化识别时间及本地时区，供后续同批缺时间候选共用；排队重试、重启和跨日恢复不会重新取时。
- [ ] 缺年时以可信原始采集日期为参考，没有则用识别日期，选择最近一个不晚于参考日的合法日期并标记年份推断。
- [ ] 无效日期或只有时分且无法确定日期时稳定回退；状态栏、外层查看器、导入及消息时间不冒充交易时间。
- [ ] 保存原始文字、最终记账时间、精度和来源，详情给出简短依据；必要字段随备份保留，旧账单不批量重算。
- [ ] 从识别入口覆盖跨年、闰日、无效日期、历史缺时间、跨日恢复、时区变化及夏令时日界；日期计算使用本地日历。
