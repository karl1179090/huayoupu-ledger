# Triage labels

工程技能使用下列五个规范角色，均映射到同名 GitHub 标签。

| 技能中的角色 | 本项目标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不计划处理 |

技能提到角色时使用对应标签。保留仓库其他已有标签；本次规格仅应用 `ready-for-agent`。后续调整标签名称时更新本表及仓库标签，使映射一致。

目标仓库与操作约定见 [issue-tracker.md](issue-tracker.md)。
