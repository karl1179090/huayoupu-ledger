# 可重试的识别批次保留分类引用

失败或已取消的识别批次仍可重试时，继续计入分类引用。删除仍有引用的分类时，用户需选择同方向的替代分类，以便剩余交易沿用已确定的分类去向。

临时失去系统采集权限时继续保留引用。原任务因授权永久失效或重试所需的截图丢失而确定无法继续时，释放该批次的分类引用，避免阻碍分类删除。

识别批次保留引用期间，以识别时保存的整套分类规则计算分类引用。这与备份恢复对整套规则的目标分类校验一致。

删除分类的预览与确认都依据当时的任务重试状态核对引用。引用发生变化时，刷新删除影响并请用户重新确认。

备份恢复时，按恢复后的任务能否重试重新计算分类引用。可以继续的批次保留引用，确定无法继续的批次保留可查看的识别历史并释放引用。
