# 已验证版式的节点选路

现场采集保留 `NodeSnapshot`，其中只有不可变值：应用、窗口、活动、内容代次、应用／系统／设备版本、读取时钟，以及节点的父子关系、屏幕坐标、文字、内容描述、控件类型和状态。不会把 `AccessibilityNodeInfo` 放入队列。完整树仍不等于全部像素文字已经公开。

生产遍历继续先检查应用选择、授权、窗口归属和隐私，再读取内容。密码或可编辑控件不读取值；空树、敏感页面、400 节点／64 层／80 子节点限制、单字段或累计文字限制及完整 UTF-8 证据超过 256 KiB 均不能借截图绕过。每个后代也必须属于目标窗口。

截图请求前再次读取并比较完整语义指纹，而非仅比较窗口 ID。截图提供者在帧交付时检查授权和内容代次；采集期间收到目标内容变化（包括缺窗口 ID 的同应用内容事件）会失去原授权，不能改用 OCR 读取新页面。已交付的安全指定窗口截图可以在用户离页后继续处理。旧系统保留原有截图后的窗口归属检查。

## 适配资格与处理

`NodeRecognitionRegistry.production` 只启用一个精确范围：微信 8.0.79／版本号 3182，Samsung SM-S9210、Android 16／API 36 的已记录系统构建，手动识别 `ChattingUI` 中独立的服务通知与已完成零钱扣款卡。真实对照 ID 为 `f754a6a2-b387-4339-9ece-296b5e122fe2`；生产服务节点与原图、字段归属及本地只读解析已通过对照。其他应用、版本、设备、系统或自动采集不在该适配范围。合成适配只通过测试构造器注入，不能独立证明真实兼容性。

启用适配前，必须在真实来源应用的同一页面，用生产服务遍历取得节点，与原分辨率截图及第二次节点快照对照。记录对照 ID、应用版本与版本号、系统、设备、活动、手动／自动范围及已验证字段；原始材料留在本机私有目录。手动打开的历史详情不能证明即时自动支付结果兼容。

适配资格匹配精确版本及稳定的结构／标签规则。单次采集的完整文字指纹只绑定该次交易，不能作为只允许某个金额、商家或日期的版式条件。

已验证适配产生有效单笔候选时，调用现有 `CaptureProcessor` → `CaptureCoordinator` → 账本事务；时间、分类、钱包与提交幂等没有第二套实现。节点字段使用 `source=node`，采集信封提供的字段保留 `source=capture`。缺少商家、订单内容、订单号或时间不会单独追加 OCR；缺时间沿用统一的识别时间回退。

未知版式、解析无效或冲突使用同一张保存截图执行一次 OCR。图片导入直接 OCR，不读取旧页面节点。首次实际解析／识别才固定识别时间；分类配置在任务创建时独立固定。队列重开使用保存的截图与节点，不重新采集或授予权限。

## 存储与查看

`recognition.db` 版本 8 增加独立的节点快照、截图字节指纹和识别证据列。规则快照与节点快照分别投影读取，合法的接近 2 MB 分类配置不会因同一行新增节点而超过 CursorWindow 的整行读取容量。

任务及账单详情的 `recognitionEvidence` 包含选路、原因、版式对照、快照摘要、截图状态与可用阶段耗时。原始节点树不进入通用诊断或界面桥接。`ReceiptEvidence.recognition` 是兼容的可选结构，随已有账单备份保存；删除识别任务后仍能解释账单来源。完整任务恢复／跨库备份由后续备份工作统一处理，`portableNodeEvidence()` 提供基于稳定 operationKey 和账单 UID 的私有导出边界，不使用行号或媒体 owner 作为便携身份。

耗时按节点读取、截图、选路、解析、OCR、保存分别记录；未实际发生的阶段不填。正常 OCR 的计时排除等待推理许可的时间。模拟器耗时不能作为真实设备性能结论。

普通截图不可用或超时目前仍按采集失败终止。`ScreenshotAcquisitionException` 已区分普通不可用／超时、系统保护、授权变化和窗口变化，供后续仅在可靠节点证据下继续保存的工作使用。

## 本地诊断构建

用 `-PledgerNodeDiagnostic=true` 构建 debug，并可用 `-PledgerAppBuildDir=<独立目录>` 隔离输出。应用 ID 是 `net.ankio.ledger.nodediagnostic`，有独立的诊断应用与无障碍服务标签；不覆盖现有记账应用。普通 debug 的接收器禁用，release 不包含该接收器。

诊断接收器要求本地 `DUMP` 权限，只响应显式 `NODE_COMPARE` 请求。用户仍须手动启用该应用的无障碍服务、摇一摇开关和来源应用选择；诊断不改变这些授权，不在连接时自动采集。采集复用生产目标、隐私、树遍历与截图提供者，并要求截图前后节点一致。结果只写私有 0700 目录中的 0600 文件；不创建识别任务、不运行识别器、不提交账单。真实设备只由设备持有人协调操作；模拟器夹具不能用于覆盖个人设备上的支付应用。
